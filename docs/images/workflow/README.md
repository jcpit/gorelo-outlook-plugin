# Workflow image notes

These five PNGs are illustrative mockups created for this project's documentation,
not captures of a live mailbox, Microsoft tenant or Gorelo customer environment.
All displayed people, companies, email addresses, ticket numbers and device data
are fictional; email addresses use reserved example domains.

- `launch.png`: Outlook context and Microsoft sign-in; sign-in copy is simplified.
- `review.png`: email review, ticket routing, contacts and linked assets.
- `created.png`: ticket confirmation and attachment recovery; explanatory states
  are combined, and duplicate protection is local to the browser profile.
- `tickets.png`: ticket details, conversation and adding the selected email.
- `assets.png`: asset list and details combined to explain last-logon suggestions.

Copies were visually reviewed and stripped of ancillary metadata before inclusion.
Do not replace them with live diagnostic/customer screenshots without a new
privacy review. Never include credentials, real mail content, tenant settings or
customer identifiers in documentation imagery.
